SHA3-512 at a glance

Output512 bits (128 hex characters)
Rate / capacity576 / 1024 bits
Collision resistance256 bits
Preimage resistance512 bits
StandardNIST FIPS 202 (2015)

Where it is used

ML-KEM (FIPS 203) uses SHA3-512 as its G function. Choose SHA3-512 when you want the widest security margin, for example long-term archives or very high-value signatures.
