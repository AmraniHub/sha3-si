SHAKE256 hash calculator

SHAKE256 is an extendable-output function (XOF) from the SHA-3 family: instead of a fixed digest, you ask for exactly as many bits as you need, with up to 256-bit security.

SHAKE256 at a glance

Outputany length you choose
Rate / capacity1088 / 512 bits
Securityup to 256 bits (collision: min(d/2, 256))
StandardNIST FIPS 202 (2015)
SiblingSHAKE128: rate 1344, up to 128-bit security

Where it is used

SHAKE256 is used in Ed448 signatures (RFC 8032), in ML-DSA and ML-KEM, and in the SHAKE variants of SLH-DSA. Set the output length above to the size your protocol needs.
