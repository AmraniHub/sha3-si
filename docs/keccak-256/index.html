Keccak-256 hash calculator

Keccak-256 is the original Keccak submission with a 256-bit output, before NIST changed the padding for SHA-3. Ethereum and every EVM chain use it, which is why it gives different results from SHA3-256.

Keccak-256 at a glance

Output256 bits
Padding byte0x01 (SHA3-256 uses 0x06)
Used byEthereum, Solidity keccak256(), EVM chains
Function selector of transfer(address,uint256)0xa9059cbb (first 4 bytes of the hash)

Where it is used

Ethereum uses Keccak-256 for addresses (the last 20 bytes of the hash of the public key), transaction hashes, storage slots and the 4-byte function selectors that every contract call starts with. Type transfer(address,uint256) above and the first 8 hex characters are the selector.
