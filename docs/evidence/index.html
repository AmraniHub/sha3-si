Verify a record

Paste a record fingerprint from any sha3.si report. The Merkle proof is recomputed in your browser, and the Bitcoin proof can be checked with the open-source OpenTimestamps client.

How the evidence works

  1. Pages. The SHA3-256 of the exact bytes the server sent is stored with the URL, the HTTP status and the time. Change one byte and the fingerprint changes completely.
  2. Records. Each report is serialised as canonical JSON (keys sorted, no spaces) and fingerprinted with SHA3-256. The fingerprint covers the check results and every page fingerprint.
  3. Days. After each UTC day, all record fingerprints are sorted and combined pairwise with SHA3-256 into a Merkle tree. Its root is written into a small text file.
  4. Bitcoin. The SHA-256 of that file is submitted to the OpenTimestamps calendars, which commit it into a Bitcoin transaction. The proof file (.ots) can be checked by anyone with the ots client: ots verify sha3si-DAY.txt.ots.
